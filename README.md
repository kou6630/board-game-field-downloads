# ボードゲームフィールド 参加者用 v0.5.6

Windows用の参加者アプリです。インストール不要です。

1. `BoardGameField-guest.exe`をダウンロードして起動します。
2. 初回は名前を入力して「はじめる」を押します。
3. 「部屋に入る」を選び、ホストから届いた招待コードを貼り付けます。

ホストが部屋を開いている間に参加してください。
