# ボードゲームフィールド v0.5.8

Windows用アプリです。インストール不要です。

1. [参加者用アプリをダウンロード](https://github.com/kou6630/board-game-field-downloads/releases/latest/download/BoardGameField-guest.exe)して起動します。
2. 初回は名前を入力して「はじめる」を押します。
3. 「部屋に入る」を選び、ホストから届いた招待コードを貼り付けます。

ホストが部屋を開いている間に参加してください。

[ホスト用アプリをダウンロード](https://github.com/kou6630/board-game-field-downloads/releases/latest/download/BoardGameField-host.exe)

## 今回の変更

- ディジットコードの4×4の盤面に、参加者名が重ならないよう修正。
- 自分の手番で盤面を押すと「それを質問しますか？」を表示。「はい」で質問を公開、「いいえ」で取り消し。
- 「質問します」ボタンを削除。メモは上の「メモ」で切り替え。
- 誤答の入力内容をヒント欄に表示しない。

v0.5.7以降は、アプリを開き直して「更新する」で入れ替え・再起動できます。以前の版からは一度、最新版をダウンロードしてください。

[ゲスト側で起動しない時の診断ZIP](https://github.com/kou6630/board-game-field-downloads/releases/latest/download/BoardGameField-guest-diagnostic-20261011.zip)
